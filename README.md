# ドローン君

全20WAVEのストーリー付きシューティングゲームです。ブラウザだけで遊べます。

## 遊び方

| 操作 | マウス | タッチ |
|---|---|---|
| 移動 | ドローン君がポインタを追いかける | 画面のどこでもドラッグ（指の動いた分だけ動く） |
| 攻撃 | 装備が射程内の敵を自動で攻撃 | 同じ |
| 衝撃波 | クリック（燃料40） | 右下のボタン |

- WAVEクリアごとに装備を1つ獲得。相性の良い装備を2つ同時に装備するとシナジーが発動します。
- パーツで能力を強化できます（能力のリセットも可）。
- 当たり判定はドローン君中心の赤い点だけ。弾をすれすれでかすると燃料が回復します。
- 5WAVEごとにボス戦。WAVE20がラスボスです。
- 画面右下の BGM / SE で音を切り替え、`M` キーでまとめて消音。

### ふたりで協力プレイ

タイトル画面の「ふたりで協力プレイ」から遊べます（アカウント不要・インターネット接続が必要）。

1. ひとりが「部屋を作る」を押すと、4文字の部屋コードと招待リンクが出ます。
2. もうひとりは招待リンクを開くか、「部屋に入る」でコードを入力します。
3. つながるとプロローグから始まります。敵の体力は2倍、強化・装備はそれぞれ別です。

ブラウザ同士を直接つなぎます（WebRTC。最初のつなぎ合わせだけ PeerJS の公開サーバーを使います）。

## 手元で動かす

`index.html` をブラウザで開くだけで遊べます（サーバー不要）。

## ファイル構成

```

scripts/drone/
  common.js           画面・入力・ドローン君・能力・セーブ
  sound.js            BGM・効果音(Web Audio APIで合成)
  equipment.js        装備・シナジー・シナジー演出
  bosses.js           レア敵・ボス
  forces.js           同胞・人間の兵器
  mainScreen.js       戦闘画面
  dragons.js          五龍の衝撃波
  upgradeScreen.js    強化画面(能力・装備・報酬)
  gameoverScreen.js   ゲームオーバー画面
  story.js            ストーリー・エンディング
  coop.js             ふたりで協力プレイ
  draw.js             描画ループ
images/game/          ドローン君・ポインタの画像
lib/peerjs.min.js     PeerJS(協力プレイの通信。MITライセンス)
tools/                動作確認用のテスト
```

## 開発用の機能

- タイトル画面で `Q` キー：戦闘なしでストーリーだけを順に確認できます（`Esc` でタイトルへ）。
- 動作確認：`powershell -ExecutionPolicy Bypass -File tools\run-smoke.ps1`（ヘッドレスのEdgeで1人用と協力プレイを自動テスト。数秒）。
- 開発の決まりごとや構成の詳しい説明は `CLAUDE.md` にあります。
